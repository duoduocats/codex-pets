# Codex Pets — macOS Codex 宠物主题商店

简体中文 · [English](README.en.md) · [下载最新版](https://github.com/duoduocats/codex-pets/releases/latest)

在 Mac 上**发现、预览、收藏和安装 Codex 社区宠物**，为你的 Codex 桌面应用选一个小伙伴。

原生 macOS 应用，支持 **Apple Silicon · macOS 13+**。浏览商店无需额外登录或 API Key。

## 主要功能

- **发现社区宠物**：默认按来源热度排序，可切换名称排序、筛选来源或搜索宠物及署名。
- **完整动作预览**：轮播全部动作，单击动作按钮即可切换并播放，支持暂停与继续；v2 宠物还可预览环视。
- **本地收藏**：点击书签，将喜欢的宠物集中保存在“收藏”中；来源暂时离线时仍可查看已保存的信息。
- **安装到本机**：确认署名、授权与保存位置后安装，再到 Codex 设置中选择使用。
- **卸载与恢复**：在“已安装”将宠物移到系统废纸篓，可恢复，收藏保留。
- **多个社区来源**：内置 12 个来源，可分别启用或关闭，也可添加最多八个[兼容公开目录](docs/pet-catalog.md)。
- **设置指引**：查看安装后的使用步骤，通过 ×、关闭按钮或 Esc 退出。
- **中英文界面**：跟随 macOS 首选语言，适配深浅色外观和减少动态效果。

## 社区来源与热度

内置来源包括 Petdex、codex-pet.com、Codex PokéPets、Pets Codex、codexpets.org、明日方舟宠物，以及 HuaqingAI、Cute-chen、legeling、Senyo、David、Rito 的合集。不同来源保留各自的署名、授权和原始链接；未提供作者或素材授权时会明确标注。

热度来自 Codex Pet Gallery 的公开统计快照，只代表该来源的安装及喜欢记录。没有统计的宠物显示“—”，详情可查看快照时间；这些记录不代表全球使用量。

## 下载与首次安装

1. 从 [GitHub Releases](https://github.com/duoduocats/codex-pets/releases/latest) 下载 **arm64 DMG** 并打开。
2. 将 **Codex Pets.app** 拖入右侧的 **Applications（应用程序）**。
3. 从应用程序目录打开 Codex Pets，浏览社区宠物。

安装包内提供拖拽安装背景和 **[中英文图文安装指南](docs/install/Installation-Guide.pdf)**，首次安装可直接查看。

### macOS 提示无法验证开发者时

当前发布包使用 ad hoc 签名，尚未经过 Apple 公证。确认安装包来自本仓库后：

1. 尝试打开应用一次，关闭拦截提示。
2. 打开 **系统设置 → 隐私与安全性**，向下找到 Codex Pets 的提示，点击 **仍要打开**。
3. 按系统提示完成确认，再点击 **打开**。

该应用会被保存为安全性例外。以上适用于开发者身份或公证提示；若系统报告恶意软件或文件损坏，请停止安装并重新检查下载来源。步骤依据 [Apple 官方说明](https://support.apple.com/zh-cn/102445)。

## 安装与使用宠物

1. 选择一个宠物，查看完整动作、来源和授权。
2. 点击 **安装到本机**，核对信息并确认。
3. 打开 Codex 设置，手动选择左侧 **虚拟宠物**，刷新后选择刚安装的宠物。

选择使用、切换宠物与恢复默认均在 Codex 中进行。在 **已安装** 中点击废纸篓并确认可卸载宠物；卸载正在使用的宠物前，先在 Codex 中切换到其他宠物。

## 默认设置

| 设置 | 首次打开默认值 |
| --- | --- |
| 发现页排序 | 来源热度，可切换名称排序 |
| 动作预览 | 轮播全部动作，可暂停或单击切换 |
| 社区来源 | 12 个内置来源开启，可分别关闭 |
| 界面语言与外观 | 跟随 macOS |

收藏和来源选择保存在本机，重新打开应用后仍保留。

## 轻量与隐私

原生 macOS 应用，当前安装包约 **2.6 MB**。读取公开社区资料和本机宠物目录，不读取 ChatGPT / Codex 登录凭据、聊天内容或项目代码。收藏保存在这台 Mac，安装与卸载均由你确认。

## 常见问题

### 为什么安装后看不到宠物？

在 Codex 设置中手动进入 **虚拟宠物**，刷新列表并选择。商店里的设置入口会打开 Codex 设置首页，需要手动选择宠物页签。

### 点击“在 Codex 中确认安装”没有反应？

“…”中的这个方式需要 Codex 支持安装确认窗口。没有弹窗时，请使用商店的 **安装到本机**，再按上面的步骤选择使用。

### 为什么动画预览暂停了？

窗口隐藏、遮挡、最小化或失活时会停止预览；系统开启减少动态效果时也会停止自动播放。可在详情中暂停或继续，单击一个动作即可切换预览。

### 支持 Intel Mac 吗？

当前发布包仅支持 Apple Silicon（arm64），最低系统为 macOS 13。

### 如何切换界面语言？

支持简体中文和英文，默认跟随 macOS 首选语言。也可在系统设置中单独设置应用语言，重新打开应用后生效。
