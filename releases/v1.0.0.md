# Codex Pets 1.0.0

## 更新内容

- 独立原生 macOS 宠物主题商店，接入十二个社区来源，支持搜索与来源筛选。
- 默认按来源热度排序，可切换名称排序；显示有出处和快照时间的真实热度。
- 完整动作轮播，单击动作按钮即可切换并播放；支持暂停与 v2 环视。
- 本地收藏，安装确认、本机主题检索和卸载到系统废纸篓。
- Codex 设置指引，可通过关闭按钮、× 或 Esc 退出。
- 与 Codex Buddy 同源猫头及盘尾图标，浅色红底白猫、深色黑底红猫，支持系统分层材质。
- 中英文、深浅色和减少动态效果适配。

## What’s new

- A standalone native macOS store with twelve community sources, search and source filters.
- Source popularity is the default order, with name order available and attributed snapshot counters.
- All animation states, single-click action selection, pause/resume and v2 directional looking.
- Local favorites, confirmed local installation, installed-pet discovery and removal to system Trash.
- Codex settings guidance that closes with Close, × or Esc.
- A shared Codex Buddy cat head with a curled tail, red/white Default and black/red Dark layered icon.
- English/Simplified Chinese, light/dark appearance and reduced motion.

## 安装 / Install

Apple Silicon · macOS 13+. Download the arm64 DMG, drag Codex Pets into Applications, then open it. The DMG includes an illustrated Chinese/English installation guide. This build is ad hoc signed and not Apple-notarized. Selection of an installed pet remains in Codex settings.
